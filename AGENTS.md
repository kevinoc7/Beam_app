# Beam App Layout

This is a single-file web app. GitHub Pages entry points and project instructions live at the repository top level:

- `index.html` - the web app.
- `spec.md` - the project specification.
- `prompts.md` - prompts and prompt notes.
- `AGENTS.md` - repository layout and file-placement guidance.

Supporting work is organized in numbered folders:

- `00_planning/` - notes, sketches, and planning artifacts.
- `01_data/` - source data, datasets, and data files.
- `02_validation/` - hand calculations, test cases, and validation records.
- `03_output/` - screenshots and exported results.

Save every new file in the folder that matches it. Keep the app implementation in `index.html` and its project documentation in `spec.md`, `prompts.md`, or the appropriate folder README. Do not place project artifacts outside these locations.

- After each request, add an entry to prompts.md: what I asked, what you changed, and whether it worked.
